# ToDoList application

A simple and fast To‑Do application built in Python 👍

This repository contains only the installer for my ToDoList application.
The full source code is in a separate private repository.

(installer can be downloaded from 'releases')



The ToDoList app includes:

    Clean and simple UI

    Task creation, editing, deleting, reordering, notes

    Automatic saving

    History tracking

    Many themes, even more fonts, and some language options
